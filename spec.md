# Спецификация: URL Shortener (DIY)

## Что строим:
- Функция для сокращения длинного URL до короткого кода.
- Функция для получения оригинального URL по короткому коду.
- Хранение данных: в оперативной памяти (Python dictionary).

## Чего НЕ строим:
- Базу данных, кастомные ссылки, статистику.

## Acceptance Criteria:
1. `shorten_url("https://example.com")` возвращает короткий код.
2. `get_original_url("короткий_код")` возвращает `"https://example.com"`.
3. `get_original_url("несуществующий_код")` возвращает `None`.
